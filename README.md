# Бенчмарк ускорения инференса

Набор экспериментов по методам ускорения инференса на модели сегментации UNet (датасет Oxford-IIIT Pet). Сравниваются: FP16-базовая линия, `torch.compile`, ONNX Runtime, Post-Training Quantization (PTQ), Quantization-Aware Training (QAT) и структурный прунинг.

## Установка

```bash
pip install -r requirements.txt
```

Скачать датасет:

```bash
bash scripts/download_data.sh
```

## Использование

```bash
python run_experiment.py <команда>
```

| Команда    | Описание                                        |
|------------|-------------------------------------------------|
| `train`    | Дообучение базовой модели                       |
| `baseline` | Бенчмарк базовой линии FP16                     |
| `compile`  | Бенчмарк `torch.compile`                        |
| `backend`  | Бенчмарк ONNX Runtime                           |
| `ptq`      | Квантизация после обучения (PTQ)                |
| `qat`      | Квантизация в процессе обучения (QAT)           |
| `prune`    | Прунинг + восстановительное дообучение          |
| `profile`  | Профилирование выполнения модели                |
| `report`   | Генерация сводных таблиц                        |
| `all`      | Запуск всех экспериментов последовательно       |

## Структура проекта

```
project_f1/
├── configs/          # YAML-конфиги (train, baseline, compile)
├── data/             # Датасет (oxford-iiit-pet)
├── results/          # Результаты: чекпоинты, логи, таблицы, графики
├── scripts/          # Вспомогательные скрипты обучения и бенчмарков
├── src/
│   ├── benchmark/    # Бенчмаркинг и отчётность
│   ├── data/         # Датасет и загрузчики данных
│   ├── inference/    # Бэкенды инференса (ONNX, compile)
│   ├── models/       # Архитектура UNet
│   ├── training/     # Циклы обучения (QAT, прунинг)
│   └── utils/        # Конфиг, логирование, сиды
└── run_experiment.py # Единый запускатель экспериментов
```

## Результаты

После запуска экспериментов сводные таблицы сохраняются в `results/tables/`. Пересгенерировать их можно командой:

```bash
python run_experiment.py report
```
